# きいちアプリ

小学生むけ、すうじで あそべる ブラウザアプリ。PC・スマホ・タブレットで うごきます。

## つかいかた
`index.html` をブラウザで ひらくだけ。インストールも つうしんも いりません。

## きのう
| タブ | ないよう |
|---|---|
| 🕐 とけい | アナログ＋デジタル時計、日付、時刻のよみかた |
| 📅 カレンダー | 月の表示、前後の月へ移動、日付をタップして日数計算 |
| 🧮 でんたく | たす・ひく・かける・わる（キーボードもOK） |
| ⏱️ ストップウォッチ | 計測・ラップ・リセット |
| 🧩 1024パズル | 同じ数をくっつけて1024をめざす（矢印キー / WASD / スワイプ） |
| ➕ けいさんチャレンジ | 四則演算クイズ10問。5モード×3レベル |
| 🎯 かずあて | 1〜100のひみつの数をあてる |
| 👆 すうじタッチ | 1〜25を順にタッチするタイムアタック |
| 🔍 ヒット＆ブロー | 3けた・4けたの ひみつの数を ヒット／ブローのヒントで あてる |

## ファイル
- `index.html` … アプリ本体（これ1つで完結）
- `docs/` … 要件定義・仕様・設計・開発メモ・検証報告
- `tests/test.js` … 自動テスト（`node tests/test.js` で実行、105ケース）

## こうかい版（ブラウザで ひらくURL）
https://tkamiyoshi.github.io/Private_tools/kiichi-app/

スマホ・タブレットは このURLが かんたんです。だれでも ひらけます。
GitHub Pages（リポジトリ `tkamiyoshi/Private_tools` の main ブランチ）から 配信しています。

## 手を入れるときの ながれ
1. `index.html` を なおす
2. `node tests/test.js` … テストが ぜんぶ PASS することを かくにん（105ケース）
3. コミットして main に push する … 1〜2分で こうかい版に はんえいされます（URLは かわりません）

`tools/build-artifact.js` は まえの こうかい先（Claude の Artifact）用の ビルドです。いまは つかっていません。
`dist/` は 生成物なので Git では ふくめていません。
