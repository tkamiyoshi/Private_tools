ハンドアウトカードメーカー

テキストを貼り付けると自動でカード化します。「ハンドアウト」で始まる行ごとに1枚。
読み取る項目：ハンドアウト / ワークス / カヴァー / ロイス / 推奨感情 / 残りはあらすじ

コンビニプリントの手順
  1. 「印刷 / PDF保存」→ 送信先を PDFに保存
  2. 用紙 A4・余白 なし・倍率 100%・背景のグラフィック ON
  3. 保存したPDFを netprint（セブン）や ネットワークプリント（ローソン・ファミマ）に登録
  4. 店頭で A4 / 等倍（拡大縮小なし） で印刷し、点線に沿ってカット
あらすじが長くて入りきらない場合は文字を自動で縮小します。それでも溢れるとカード下部にピンクの線が出るので、サイズを大きくするか文章を短くしてください。
