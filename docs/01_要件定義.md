# きいちアプリ 要件定義書

担当部署: 要件定義部
版: 1.0 / 2026-08-27

## 1. 目的
小学生が「かず」に親しみながら、日常でも使える便利ツールをひとつにまとめたブラウザアプリを提供する。

## 2. 対象ユーザー
- 主対象: 小学生（低学年〜高学年）
- 副対象: 保護者（横で一緒に使う）

## 3. 利用環境
| 区分 | 条件 |
|---|---|
| デバイス | PC / スマートフォン / タブレット |
| ブラウザ | Chrome, Edge, Safari, Firefox の最新版 |
| 通信 | インストール不要。HTMLファイルを開くだけで動作（オフライン可） |
| 入力 | マウス・キーボード・タッチ（スワイプ）すべて対応 |

## 4. 機能要件
| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| F-01 | タブ切り替え | 全機能を1画面でタブ切替。状態は保持 | 必須 |
| F-02 | とけい | アナログ＋デジタル時計、日付、時刻の読み方表示 | 必須 |
| F-03 | カレンダー | 月表示、前後の月へ移動、今日を強調 | 必須 |
| F-04 | でんたく | 四則演算、大きなボタン | 必須 |
| F-05 | ストップウォッチ | 計測・停止・リセット・ラップ | 必須 |
| F-06 | 1024パズル | 2048風スライドパズル。目標1024 | 必須 |
| F-07 | けいさんチャレンジ | 四則演算クイズ10問。難易度3段階 | 提案・採用 |
| F-08 | かずあてゲーム | 1〜100の数当て。大小ヒント | 提案・採用 |
| F-09 | すうじタッチ | 1〜25を順にタッチするタイムアタック | 提案・採用 |
| F-10 | ヒット＆ブロー | 1人用。3けた／4けた（数字の重複なし）。ヒット・ブロー表示、ベスト回数保存 | 追加・採用 |

## 5. 非機能要件
- N-01 安全性: 個人情報を扱わない。外部通信なし。広告なし。
- N-02 可読性: 小学生が読める漢字＋ひらがな。文字は大きめ（本文16px以上）。
- N-03 操作性: タップ領域は44px以上。誤操作しても壊れない。
- N-04 応答性: 操作の反応は100ms以内。
- N-05 記録: ハイスコア等は端末内（localStorage）のみに保存。使えない環境でも動作継続。
- N-06 レスポンシブ: 320px幅〜大画面まで崩れない。横スクロールを発生させない。

## 6. 対象外（スコープ外）
- ログイン／アカウント、サーバー保存、ランキング共有、課金、通知
