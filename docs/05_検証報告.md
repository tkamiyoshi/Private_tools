# きいちアプリ 検証報告書

担当部署: 検証部
版: 1.0 / 2026-08-27
対象: `index.html`（開発部 提出版）

## 1. 検証方法
1. **静的検証**: `node --check` によるJavaScript構文検査
2. **自動テスト**: 最小DOMシムを用意し、`index.html` 内の**実コードをそのまま実行**して振る舞いを検査（`tests/test.js`）
   - 実装のコピーではなく本体コードを読み込むため、本体を直せばテストも追従する
3. **反復実行**: 乱数を使う機能があるため10回連続実行し、結果が揺れないことを確認

## 3. テストケース一覧

### T1 起動時の初期化（8件）
時計のHH:MM:SS書式、日付行、よみかた（ごぜん/ごご）、カレンダーが6週42マス生成、電卓の初期値0、すうじタッチが25マスで1〜25重複なし

### T2 タブ切り替え（4件）
パネルの表示切替、`aria-selected` の更新、選択タブのlocalStorage保存

### T3 でんたく（13件）
`12+8=20` / `7×6=42` / `9−15=-6` / `7÷2=3.5` / **`0.1+0.2=0.3`（浮動小数点の誤差が出ないこと）** / 連続演算 `2+3+4=9` / **0除算でエラー表示とCによる復帰** / ←の1文字削除 / ±の符号反転 / 小数点の二重入力防止 / 12桁での入力打ち止め / キーボード入力

### T4 1024パズル（9件）
開始タイル2枚が2または4、キー操作で盤面が変化、全タイルが2の累乗、**ランダム操作4,000手で必ず終局し無限ループしない**、終局メッセージ、スコア加算、ベストスコア保存、リセット動作

### T5 けいさんチャレンジ（6件）
**全5モード×3レベルで600問を生成し、以下をすべて検証**
- 式の形式が正しい／ひきざんの答えが負にならない／わりざんが必ず割り切れる
- 選択肢がちょうど4つ・重複なし・マイナスを含まない・**正解が必ず含まれる**

加えて、10問全問正解での結果画面遷移と⭐⭐⭐判定、誤答時の正解表示、**連打による二重回答の防止**

### T6 かずあて（5件）
二分探索で7回以内に必ず正解に到達（ヒントの大小が常に正しい）、正解後の入力無効化、履歴の記録、範囲外入力・非数値入力のエラー案内（クラッシュしない）

### T7 すうじタッチ（6件）
順番外のタッチで進まない、誤タッチの視覚フィードバック、1〜25完走、全マス完了表示、ベストタイム保存と表示

### T8 ストップウォッチ（6件）
初期表示、スタート/ストップのラベル切替、ラップ記録、リセットによる時刻・ラップ・ボタンの復帰

### T9 カレンダー（6件）
前月・翌月移動、往復での一致、**26か月進めても年跨ぎで壊れない**、きょうへ戻る、日付タップ時の「きょうだよ！」「3日あと」表示

### T11 指摘3点の回帰テスト（15件）※版1.1で追加
**(1) 1024達成後に続きが遊べること**
- 乱数を固定し、テスト側の先読み探索ボットで**実際に1024タイルまで到達**させて検証（決定的に再現する）
- 達成メッセージが出る／「つづける」ボタンが出る／**オーバーレイ表示中はキー操作で盤面が動かない**／「つづける」でオーバーレイが閉じる／**閉じた後に操作を継続できる**／1024タイルが盤面に残っている／新規開始時は「つづける」が隠れる
- ゲームオーバー時には「つづける」が出ないことも確認

**(2) すうじタッチのベスト記録**
- **0.0秒でクリアした場合でも**ベストが保存され、表示が `-` にならない／シャッフル後も表示が残る

**(3) ストップウォッチのラップ**
- 未スタート時のラップは無視される／**スタート直後（経過0ms）でもラップが記録される**／連続ラップが積み上がる／**ストップ中でもラップを記録できる**

### T12 異常系（1件）
**localStorage が例外を投げる環境（プライベートモード等）でもアプリが起動し動作継続する**

## 4. 検出した不具合と対応
| # | 重要度 | 内容 | 対応 | 再検証 |
|---|---|---|---|---|
| 1 | 中 | すうじタッチのベストタイムが `0` と未記録を区別できず、表示が `-` のまま残る | 未記録を `null` で管理するよう修正 | PASS |
| 2 | 低 | ストップウォッチ開始直後（経過0ms）にラップが効かない | 判定条件を「未スタート」に変更 | PASS |
| 3 | 低 | ストップウォッチの初期表示がHTML直書きのみに依存 | JS起動時にも初期化 | PASS |

いずれも修正済み。修正後の全件再実行でFAILなし。

### 版1.1で追加検出した不具合
| # | 重要度 | 内容 | 対応 | 再検証 |
|---|---|---|---|---|
| 4 | 中 | 1024達成のオーバーレイ表示中でも、矢印キー/スワイプが盤面に届き、**見えないところで盤面が動いてしまう** | `move()` にオーバーレイ表示中の入力ガードを追加 | PASS |
| 5 | 低 | ストップウォッチを止めた状態でラップが押せない場合があった（経過0msでの判定に依存していた） | 「一度でもスタートしたか」を表す `started` フラグで判定するよう変更 | PASS |
