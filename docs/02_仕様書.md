# きいちアプリ 仕様書

担当部署: 仕様策定部
版: 1.0 / 2026-08-27

## 1. 全体仕様
- アプリ名: きいちアプリ
- 画面構成: ヘッダー（アプリ名）＋タブバー（横スクロール可）＋コンテンツ領域
- タブは8つ。初期表示は「とけい」
- 配色: 明るいオレンジ／黄色を基調。各機能にテーマ色を割り当て
- 文言: 小学生向け。ボタンは動詞（「スタート」「もどる」など）

## 2. 機能別仕様

### 2.1 とけい
- アナログ時計（SVG）: 短針・長針・秒針、1〜12の文字盤、目盛り
- デジタル表示: HH:MM:SS（2桁ゼロ埋め）
- 日付: YYYY年M月D日（曜日）
- 読み方: 「ごぜん 9じ 5ふん」のように日本語で表示（午前/午後）
- 更新間隔: 200ms

### 2.2 カレンダー
- 月表示（日〜土の7列）。前月・翌月ボタン、「きょう」ボタン
- 日曜=赤、土曜=青、今日=丸くハイライト
- 当月以外の日はグレー表示
- 日をタップすると「◯月◯日（◯）／きょうから◯日後」を表示

### 2.3 でんたく
- 演算: ＋ − × ÷、小数点、= 、C（全消去）、←（1文字消し）
- 表示: 上段に途中式、下段に現在値（最大12桁）
- 0除算は「エラー」表示しCで復帰
- 誤差対策: 結果は小数8桁で丸め
- キーボード入力にも対応（数字/+-*/ /Enter/Backspace/Esc）

### 2.4 ストップウォッチ
- 表示: MM:SS.CC（1/100秒）
- ボタン: スタート／ストップ、ラップ、リセット
- ラップは一覧表示（新しい順、区間タイムと合計タイム）

### 2.5 1024パズル
- 4×4グリッド。開始時にタイル2枚（2または4）
- 操作: 矢印キー / WASD / スワイプ
- 同じ数字が合体して倍に。移動できた時のみ新タイル出現
- 1024到達で「クリア！」表示、そのまま続行可
- 動かせる手が無くなったら「おしまい」
- スコアと最高スコアを表示・保存
- 「もういちど」ボタン

### 2.6 けいさんチャレンジ
- モード: たしざん／ひきざん／かけざん／わりざん／ミックス
- レベル: ★1（かんたん）★2（ふつう）★3（むずかしい）
- 全10問、4択。正誤を即時表示し自動で次の問題へ（0.7秒）
- 結果画面: 正解数・かかった時間・評価（★3段階）

### 2.7 かずあてゲーム
- 1〜100の秘密の数を当てる。入力後「もっと大きい／小さい／せいかい」を表示
- これまでの回答履歴を表示。回数に応じて評価コメント
- 「あたらしいゲーム」ボタン

### 2.8 すうじタッチ
- 5×5に1〜25をシャッフル配置。1から順にタッチ
- 最初のタッチで計時開始、25で終了
- 間違いタッチは赤く点滅（ペナルティなし）
- ベストタイムを保存

## 3. データ保存（localStorage）
| キー | 内容 |
|---|---|
| kiichi.puzzle.best | パズル最高スコア |
| kiichi.touch.best | すうじタッチ最速タイム |
| kiichi.tab | 最後に開いていたタブ |

読み書きは try/catch で保護し、失敗しても機能は動作する。
