# きいちアプリ 設計書

担当部署: 設計部
版: 1.0 / 2026-08-27

## 1. 方式設計
- 構成: 単一ファイル `index.html`（HTML＋CSS＋JS内包）
  - 理由: インストール・ビルド不要。ファイルをダブルクリックで起動でき、学校/家庭のどちらでも配布しやすい
- ライブラリ: なし（バニラJS）。外部通信ゼロ＝オフライン動作・安全
- 文字コード: UTF-8 / `<meta name="viewport">` でレスポンシブ

## 2. 画面設計
```
┌───────────────────────────┐
│  🔢 きいちアプリ              │ ヘッダー（sticky）
├───────────────────────────┤
│ [とけい][カレンダー][でんたく]… │ タブバー（横スクロール, sticky）
├───────────────────────────┤
│                           │
│      機能パネル（1つだけ表示）    │
│                           │
└───────────────────────────┘
```
- ブレークポイント: 600px（スマホ/タブレット以上）
  - 〜600px: 1カラム、ボタン等倍、タブは横スクロール
  - 600px〜: 最大幅 720px 中央寄せ、余白拡大

## 3. モジュール構成（JS内の名前空間）
| モジュール | 役割 | 主な関数 |
|---|---|---|
| Tabs | タブ切替と状態保存 | `activate(id)` |
| Clock | 時計描画 | `tick()` |
| Cal | カレンダー生成 | `render(y,m)`, `move(n)` |
| Calc | 電卓の状態機械 | `digit()`, `op()`, `equals()`, `clear()` |
| Watch | ストップウォッチ | `toggle()`, `lap()`, `reset()` |
| Puzzle | 1024パズル | `newGame()`, `move(dir)`, `spawn()`, `draw()` |
| Quiz | 計算クイズ | `start()`, `nextQ()`, `answer(v)` |
| Guess | かずあて | `newGame()`, `check()` |
| Touch | すうじタッチ | `newGame()`, `hit(n)` |
| Store | localStorage 安全ラッパ | `get(k,d)`, `set(k,v)` |

## 4. 主要アルゴリズム

### 4.1 パズルのスライド処理
1. 方向に応じて4本のライン（行または列）を取り出す（逆方向は反転）
2. 各ラインを `slide()` で処理
   - 0を除去 → 隣接する同値を1回だけ合体（左詰め） → 0で埋める
   - 合体した値をスコアに加算
3. 盤面が変化した場合のみ、空きマスへ新タイル（90%:2, 10%:4）を出現
4. 1024が出現したら初回のみクリア演出
5. 空きが無く、上下左右いずれにも合体できなければゲームオーバー

### 4.2 クイズの選択肢生成
- 正解 `a` に対し、`a±1, a±2, a±10` 等から重複と負数を除いて3つ抽出 → 4択をシャッフル
- わりざん: 先に `b × c` を作り `(b*c) ÷ c` を出題（割り切れることを保証）
- ひきざん: 大小を入れ替えて必ず 0以上

### 4.3 スワイプ判定
- `touchstart` で座標記録、`touchend` の差分を計算
- 移動量が24px以上、かつ大きい方の軸を採用して方向決定
- 盤面上の `touchmove` は `preventDefault()` でページスクロールを抑止

## 5. エラー設計
| 事象 | 挙動 |
|---|---|
| 0で割る | 電卓「エラー」表示、Cで復帰 |
| localStorage 使用不可 | 例外を握りつぶし、既定値で継続 |
| 不正な数値入力（かずあて） | 「1〜100のかずをいれてね」と案内 |

## 6. アクセシビリティ / 操作性
- タブは `role="tab"`、パネルは `role="tabpanel"`
- タップ領域 44px 以上、フォーカスリング維持
- `prefers-reduced-motion` 指定時はアニメーション短縮
